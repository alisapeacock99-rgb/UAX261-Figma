# UAX 261 – High-Fidelity UI/UX Prototype

## Overview

**UAX 261 – Milestone 2** is a high-fidelity UI/UX design project developed as part of a group project. The project focuses on designing a clear, consistent, and user-friendly interface through a series of high-fidelity prototype screens.

The prototype was designed to demonstrate the visual layout, navigation structure, user interactions, and overall user experience of the proposed application before development.

The project includes multiple screens covering the application's **home page, user authentication, form submission, issue reporting, terms and privacy information, general information, about, and contact sections**.

---

## Features

### Home Page

* Serves as the main landing page of the application.
* Introduces users to the application.
* Provides navigation to the main sections of the system.
* Establishes the overall visual style and branding.

### Login Page

* Provides an interface for existing users to log into the application.
* Includes fields for entering user credentials.
* Designed with a simple and accessible authentication layout.

### Sign Up Page

* Allows new users to create an account.
* Provides a structured registration interface.
* Designed to make the account creation process clear and straightforward.

### Submit Form Page

* Provides users with a dedicated form for submitting information.
* Organises input fields in a clear and user-friendly layout.
* Focuses on usability and efficient information submission.

### Report Issue Page

* Allows users to report an issue or problem.
* Provides an organised interface for entering issue-related information.
* Supports clear communication between users and the system.

### Terms & Privacy Page

* Provides users with access to important terms and privacy information.
* Presents policies in a structured and readable format.
* Helps users understand how the application operates and handles information.

### Info Page

* Provides additional information about the application.
* Helps users understand the purpose and functionality of the system.
* Uses structured content to improve readability.

### About Page

* Provides information about the project/application.
* Explains the purpose and background of the system.
* Establishes context for users interacting with the application.

### Contact Page

* Provides users with a way to contact the organisation or project team.
* Presents contact information in an accessible format.
* Completes the main informational section of the application.

## Design Approach

The prototype focuses on creating a **consistent and user-centred interface** across all screens.

Key design considerations include:

* Consistent page layouts
* Clear navigation
* User-friendly forms
* Readable information hierarchy
* Consistent visual styling
* Simple and intuitive user interactions
* Clear separation between functional and informational pages
* Accessible presentation of important information

The high-fidelity design provides a visual representation of how the final application could look and function once implemented.

---

## User Workflow

### 1. Home Page

Users begin on the **Home Page**, where they are introduced to the application and can navigate to the different sections.

### 2. User Authentication

Users can access the **Login** page if they already have an account or use the **Sign Up** page to create a new account.

### 3. Form Submission

Users can navigate to the **Submit Form** page to provide the required information through a structured form.

### 4. Report an Issue

Users can access the **Report Issue** page when they need to communicate a problem or issue to the relevant organisation or system.

### 5. Information and Policies

Users can view the **Terms & Privacy**, **Info**, and **About** pages to learn more about the application, its policies, and its purpose.

### 6. Contact

Users can access the **Contact** page when they need to communicate with the project or organisation.
